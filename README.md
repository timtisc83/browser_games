# ODCE Browser Games

Single-file classroom games (ODCE, TUHH). Each game lives in its own folder and runs on GitHub Pages or locally by opening `index.html`.

| Game | Student link | Host / answer key |
|---|---|---|
| From Scoop to Dreamliner (product development cost & duration) | https://timtisc83.github.io/browser_games/product-dev-quiz/ | https://timtisc83.github.io/browser_games/product-dev-quiz/?host=true |

Game content is defined in the `GAME_DATA` / `PRODUCTS` objects at the top of each game's script.
